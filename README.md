# Taller de API - FastAPI y MongoDB

Este proyecto es mi primer taller creando una API con CRUD de aprendices (trainees).

## 🛠️ Lenguaje y Tecnologías
* **Lenguaje:** Python
* **Framework:** FastAPI
* **Base de datos:** MongoDB (PyMongo)
* **Validación de datos:** Pydantic
* **Servidor:** Uvicorn

---

## 📝 ¿Qué hice en el proyecto? (Paso a paso)

1. **Estructuración de carpetas:** Primero organicé el proyecto dividiendo los archivos de forma limpia (creando la carpeta `src`, los modelos y los controladores).
2. **Instalación de dependencias:** Instalé las librerías necesarias en el entorno virtual (`fastapi`, `uvicorn`, `pymongo`, `pydantic`, `email-validator`).
3. **Desarrollo:** Creé la conexión con la base de datos y escribí los endpoints del CRUD (Crear, Leer, Actualizar y Eliminar) para los aprendices.
4. **Control de versiones:** Inicialicé Git, organicé los cambios y subí el proyecto a mi repositorio de **GitHub**.
5. **Despliegue:** Configuré y conecté el repositorio para desplegar la aplicación en la nube utilizando **Render**.
